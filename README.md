# HPC-Programming

## Overview

This repository contains assignments for analyzing high performance computing (HPC) performance across different algorithms and computational environments. Each assignment compares execution performance on local systems versus high performance computing clusters.

## Assignments

- **Assignment 1**: STREAM benchmark operations (add, copy, scale, triad) - memory bandwidth analysis
- **Assignment 2**: Matrix multiplication with different loop orderings - cache optimization study
- **Assignment 3**: Interpolation algorithm - numerical computation analysis

Each assignment includes:
- Serial code implementations
- Performance data collected on local systems (`data_lab/`)
- Performance data collected on HPC clusters (`data_cluster/`)
- Analysis and visualization of results

## Purpose

These assignments explore how different algorithmic approaches and data access patterns impact performance in HPC environments, highlighting the differences between local and cluster-based computations.
